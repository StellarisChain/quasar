🔐 P256 Curve Only

Filter to only show wallets using the P256 elliptic curve.

{
  filter: {
    curves: ['p256']
  }
}

🔑 Secp256k1 Curve Only

Filter to only show wallets using the secp256k1 curve.

{
  filter: {
    curves: ['secp256k1']
  }
}

💎 Ethereum Assets

Filter to only show wallets that have Ethereum or ETH-based assets.

{
  filter: {
    assets: ['ETH', 'USDC', 'USDT']
  }
}

⭐ Stellaris Assets

Filter to only show wallets that have Stellaris assets.

{
  filter: {
    assets: ['STRX', 'STE']
  }
}

⛓️ Ethereum Chain

Filter to only show wallets that support the Ethereum chain.

{
  filter: {
    chains: ['Ethereum']
  }
}

💰 Minimum Balance

Filter to only show wallets with at least $100 total balance.

{
  filter: {
    minBalance: 100
  }
}

🎯 Combined Filters

Multiple filters: P256 curve + Stellaris assets + $50 minimum.

{
  filter: {
    curves: ['p256'],
    assets: ['STRX', 'STE'],
    minBalance: 50
  }
}
